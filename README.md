# Brandon Pendery — Aerospace Engineering Portfolio

An offline-ready, responsive single-page portfolio built from Brandon's project PDF, résumé, photographs, CAD images, and multi-camera test footage.

## How to use

1. Unzip the package.
2. Open `index.html` in a browser. **No installation, build tools, or account required.**
3. Use the navigation to visit Work, Test Campaign, Skills, About, and Contact. Select a project card to view details. Play the static-fire video directly on the site.

## How to publish

Upload the contents of this folder to any static host (for example, Netlify, GitHub Pages, or a standard web server). Keep the `assets` directory adjacent to `index.html` so images, video, and PDF links work. For Netlify, you can drag this unzipped folder into its manual deploy UI.

## Included sources

- Project images extracted from the supplied portfolio PDF
- Supplied valve CATIA screenshot and launch-pad photograph
- Supplied `composite-3angles` test video
- Supplied résumé and project/test-campaign PDF documents
